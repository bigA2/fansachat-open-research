# O*NET® Database Releases Archive
The current production release of the O*NET database is 31.0; see our [O*NET Database](https://www.onetcenter.org/database.html) page for more information. Current and previous releases as well as transitional releases of the database can be obtained below. 
For summary update information, see [O*NET Occupation Update Summary](https://www.onetcenter.org/dataUpdates.html). For details about each release in the archive, refer to: 
  * [O*NET Database Release Notes (30.3 and later)](https://www.onetcenter.org/dictionary/31.0/excel/appendix_updates.html)
  * [O*NET Database Release Notes (4.0 to 30.3)](https://www.onetcenter.org/dictionary/30.3/text/appendix_updates.html)


Researchers conducting longitudinal studies: see [O*NET Longitudinal Data Updates](https://www.onetcenter.org/dl_files/Longitudinal_Data_Updates.xlsx) (XLSX).
